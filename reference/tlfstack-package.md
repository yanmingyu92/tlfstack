# tlfstack: Convention-Driven Clinical Tables, Listings, and Figures in RTF

A convention stack for submission-style clinical reporting: pure builder
functions turn analysis data into tables, listings and figures; a
convention engine applies page geometry, fonts and title blocks when
rendering to Rich Text Format (RTF) through 'r2rtf'; a title resolver
reads titles and footnotes from a table-of-contents source with live,
snapshot and fallback modes; and figure rendering can run in an isolated
child process with bounded retries. The same builders serve scheduled
batch programs and interactive previews.
