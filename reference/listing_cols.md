# Default listing columns

Named character vectors (data column = display header) for
[`tbl_listing()`](https://yanmingyu92.github.io/tlfstack/reference/tbl_listing.md).

## Usage

``` r
listing_cols_ae

listing_cols_lab
```

## Format

Named character vectors.

## Examples

``` r
listing_cols_ae
#>              USUBJID                AESOC              AEDECOD 
#>            "Subject" "System Organ Class"     "Preferred Term" 
#>                AESEV              AESTDTC                AEOUT 
#>           "Severity"         "Onset Date"            "Outcome" 
#>                AEREL 
#>       "Relationship" 
```
