# Shift plot: baseline vs endpoint category

A tile grid of subject counts by baseline and endpoint reference-range
category, faceted by treatment. It uses the same pairing as
[`tbl_shift()`](https://yanmingyu92.github.io/tlfstack/reference/tbl_shift.md).

## Usage

``` r
fig_shift(df, ctx = fig_ctx(), base_size = NULL, config = NULL)
```

## Arguments

- df:

  Analysis data (BDS).

- ctx:

  A
  [`fig_ctx()`](https://yanmingyu92.github.io/tlfstack/reference/fig_ctx.md)
  list.

- base_size:

  Font size; `NULL` uses the configuration.

- config:

  A
  [`tlf_config()`](https://yanmingyu92.github.io/tlfstack/reference/tlf_config.md);
  `NULL` resolves through
  [`tlf_get_config()`](https://yanmingyu92.github.io/tlfstack/reference/tlf_get_config.md).

## Value

A ggplot.
